# Portal Web Siv (San Ignacio de Velasco)

This website began as an academic project but is dedicated to the independent promotion of culture and tourism, it integrates historical, ethnographic, and cartographic content alongside information designed to attract visitors, with the aim of preserving local identity and showcasing the city to the outside world.

### Website Content

- History page:
  - the history of San Ignacio de Velasco.
  - the history of the various places in San Ignacio de Velasco.
- Culture page:
  - Customs and traditions preserved in San Ignacio de Velasco.
- Territoy page:
  - Geographic, demographic, and hydrological data, and more.
- Tourism page:
  - Key places to visit in San Ignacio de Velasco.

## If you want to use the project

1. Make sure you have nodejs installed, you can do it for your cli, this must show a version number of nodejs.

   ```bash
   node --version
   ```

   if not, go to the official website to download and install it, version must be 22.1 or higher, you can do it from this [here](https://nodejs.org/en/download/package-manager).

2. Clone this repository:

   ```bash
   git clone https://github.com/nmmartinezp/Portal-web-siv.git
   ```

3. Install the dependences

   ```bash
   npm install
   ```
